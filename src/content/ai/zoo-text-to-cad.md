## Zoo Text-to-CAD Overview

**Zoo Text-to-CAD** layers machine learning on top of KittyCAD’s professional-grade B-rep kernel, delivering production-class solids that still obey strict dimensional constraints. The system speaks natural language prompts, but every result can be refined with KCL code, desktop tooling, or the browser-based sandbox.

### Key Features & Capabilities
- **Text-to-CAD generations** produce editable solids with feature histories you can tweak using code or traditional sketch tools
- **Desktop apps for macOS, Windows, and Linux** mirror the web preview so teams can keep iterating offline with full GPU acceleration
- **Usage-based pricing** with $10 of free credits (roughly 1,200 seconds) and metered billing at $0.0083/second once you exceed the free tier
- **Extensive sample library** ranging from medical fixtures to aerospace brackets to kickstart prompts and project setups

### 3D Printing Integration
Because the output sits on a B-rep foundation, you can export models as STEP, Parasolid, or STL while preserving design intent. Use Text-to-CAD for the first draft, then polish hole callouts or tolerance-critical faces in Zoo Design Studio before handing the file to your slicer or CAM pipeline.
