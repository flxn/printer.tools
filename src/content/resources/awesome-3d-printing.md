# Awesome 3D Printing

**Awesome 3D Printing** is a curated GitHub list that collects useful links for the wider 3D printing ecosystem. It is a community-maintained directory for discovering software, hardware, communities, and reference material from across the 3D printing space. Very similar to printer.tools itself.

Go and give it a visit if you want to find even more resources not listed on this website, or if you want to contribute to the 3D printing ecosystem by adding your own resources to the list. The repository is open for contributions and is a great way to share your knowledge and help others in the community. 

(If you do contribute, please also consider adding the resource to printer.tools if it is a great tool and not already listed here.)
